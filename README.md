# VÉLORA – Fashion E-commerce Website

A responsive fashion storefront built with HTML, CSS and JavaScript.

## Pages
- `index.html` – Home page
- `collections.html` – Product collection with search, filters and sorting
- `contact.html` – Contact form with client-side validation

## Features
- Responsive navigation menu
- Product cards generated from JavaScript product data
- Search products by name, category, occasion or colour
- Filter by category, occasion, colour and price range
- Combine multiple filters with search
- Sort by price and product name
- Clear all filters and no-results message
- Newsletter and contact form demo interactions


## Technologies
HTML5, CSS3 and JavaScript.
